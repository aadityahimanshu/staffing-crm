# Staffing CRM

A desktop Recruitment CRM built using Python, CustomTkinter and SQLite.

## Features

- Role-based Login (Head / Account Manager / Recruiter)
- Requirement Management
- Candidate Management
- JD Upload & Open
- Requirement Assignment
- Hiring Timeline
- OTP Password Reset

## Tech Stack

- Python
- CustomTkinter
- SQLite
- SQL
- SMTP
- Git & GitHub
